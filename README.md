## 个人简介

我目前就读于**同济大学国豪书院未来技术班（机器人方向）**，关注如何把人工智能方法真正落到工程系统中：从问题定义、算法原型，到仿真验证、系统集成与实际应用。

**大一综合成绩位于专业前 10%**，获评**同济大学2025-2026年度“明德之星”**。大一期间获得校级竞赛奖项 8 次、省级 1 次、国家级 4 次。目前有一篇 AI 能源方向论文以一作/共同一作身份在投。

我在 GitHub 上维护了 30 余个项目，经历主要集中在智能交通与自动驾驶安全、智慧校园数字孪生、计算机视觉和机器人系统。相比单点模型指标，我更关注完整系统能否稳定运行、清晰验证并持续迭代。

与此同时，我还运营着上百个网络社群，覆盖数千学生，是同济大学重要的传播节点之一。


## 关注方向

- **工程智能系统**：计算机视觉、时序分析、决策支持与可部署原型
- **智能交通与安全**：驾驶员状态识别、交通态势感知与实时预警
- **数字孪生与仿真**：智慧校园场景、三维建模、交互界面与工程可视化
- **机器人与具身智能**：机器人感知、仿真平台与软硬件协同
- **AI for Science / Engineering**：面向能源与工程问题的数据分析和智能建模
